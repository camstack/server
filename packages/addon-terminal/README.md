# Terminal

Interactive terminal sessions (pty + xterm) as a Dominevo addon.

Package `@dominevo/addon-terminal` on npm.

## What it provides

- **Terminal** (`terminal`): Interactive terminal sessions on any cluster node. Operators explicitly create virtual-camera instances from administrator-configured profile templates. Category: system.
  - Capabilities: `terminal-session`, `integration-instances`.

## Requirements

- Placement: any-node.
- Python: Terminal installs `python/requirements.txt` into its own environment.
- A Dominevo hub. An agent is used only where the placement above allows it.
