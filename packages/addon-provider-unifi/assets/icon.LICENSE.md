The Ubiquiti mark in `icon.svg` is the `ubiquiti` icon from the simple-icons project
(https://simpleicons.org, package `simple-icons` 16.36.0), released under
CC0 1.0 Universal (public domain dedication).

One change: `fill="#0559C9"` was added to the root element, the brand colour
declared in this addon's manifest, so the mark reads on the dark and the light
admin theme in a bare `<img>`.

The mark itself remains a trademark of its owner. It is shown only to identify
the integration.
