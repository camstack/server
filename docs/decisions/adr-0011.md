## Context

[D8](adr-0008.md) established one bus. The rule survived about as long as the next
person who needed an event to reach another node in a hurry: a direct
`broker.broadcast('camstack.evt.…')` works immediately, looks local and reasonable,
and quietly bypasses the bridging, the category taxonomy and the delivery
semantics. A single-event relay service (`$cluster-events`-style) is the same
mistake with more ceremony.

The point of this record is that D8 needed an *enforcement* decision to stay true,
and that is a separate decision from D8 itself.

## Decision

The `camstack.evt.` topic prefix and any construction of a topic string exist only
inside `packages/system/src/kernel/moleculer/event-bus.ts`. Every other file emits
through `ctx.eventBus`. No file outside that module may reference
`EVENT_TOPIC_PREFIX` or contain a raw `camstack.evt.` literal.

## Consequences

- Adding a delivery concern (batching, a new tier, tracing) is a change in one
  file rather than a search for every emitter.
- The guard is intentionally textual, so it also catches a topic assembled by
  string concatenation.

## Enforcement

`scripts/check-event-bus-usage.ts` — fails the build. Wired into CI.
