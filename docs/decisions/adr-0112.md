## Context

The Terminal camera on macOS rendered structure but no row text. The byte
stream, not the renderer, was at fault: python-build-standalone's macOS build
links ncurses statically with the terminfo database compiled out
(`--disable-database` — the code that would read `TERMINFO`/`TERMINFO_DIRS` was
never compiled in; only five fallback terminals exist) AND an ABI mismatch that
misparses every numeric capability of those fallbacks (16-bit table read at
32-bit stride: `colors=-1`, `cols=524368`). `has_colors()` is False under every
TERM value and `init_pair` is hard-blocked, so glances takes `__define_bw()`
and paints nearly every text run with SGR conceal+reverse+alt-charset
(`ESC[0;1;2;4;7;5;8m` ×1058 in 8 s). Alternatives measured and rejected: every
TERMINFO/TERMINFO_DIRS/TERMCAP variant and every fallback TERM (no env var can
reach code that does not exist); monkey-patching `has_colors` (init_pair still
blocked); running glances under Homebrew python 3.13 via PYTHONPATH onto the
managed site-packages (works, but depends on Homebrew being present);
renderer-side masking of SGR 8/`ESC(0` (hides the defect and cannot undo the
alt-charset translation).

## Decision

The addon ships prebuilt `_curses` / `_curses_panel` extension modules
(universal2, linked against the system `/usr/lib/libncurses.5.4.dylib`) in
`assets/curses-shim/py312/` and injects that directory as `PYTHONPATH` into the
glances profile env at PTY spawn, on darwin only, only when the directory
exists. PYTHONPATH precedes lib-dynload on sys.path, so the working modules
shadow the broken ones with zero changes to the managed distribution. Because
the filename is ABI-locked (`cpython-312`), a managed-python version bump makes
the shim silently inert — the addon therefore probes `tigetnum("colors")` at
startup and warns loudly when curses reports no colours.

## Consequences

Two ~180 KB binaries live in the repo and in the published package. A
managed-python bump to 3.13 requires rebuilding the shim (recipe in the session
log, 2026-08-12); until then the probe warn is the tripwire. `_curses_panel`
must ship alongside `_curses` — glances imports `curses.panel`, and mixing the
shimmed `_curses` with the stock static panel module would load two ncurses
instances in one process.

## Enforcement

`curses-shim.spec.ts` (darwin-only, shim-dir gating, PYTHONPATH prepend). The
startup probe is the runtime guard; nothing static checks the ABI tag against
the managed python version — review only on python bumps.
